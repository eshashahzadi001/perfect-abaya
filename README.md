# Esha Shahzadi – Abaya Boutique Website

A responsive static website concept for a luxury women's Abaya boutique.

## Project folders
- `html/index.html` — website page
- `css/style.css` — custom styles
- `js/script.js` — small interactive behaviors
- `assets/images/` — generated collection concept image
- `bootstrap/` — Bootstrap setup notes

## Run locally
Open `html/index.html` in a browser. Bootstrap 5 and Google Fonts are loaded from CDNs, so an internet connection is needed for those external resources.

## Before publishing
1. Replace the concept image with your actual product photography.
2. Update `hello@example.com` with your real business email.
3. Add your WhatsApp number and social media links.
4. Add actual product names, prices, sizes, and ordering details if you plan to sell online.
5. A static contact button opens the visitor's email app; a working online contact form requires a form service or backend.

This is a front-end website template, not a complete e-commerce checkout system.
